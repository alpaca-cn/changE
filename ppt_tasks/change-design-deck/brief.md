# Brief

- **Topic**: changE —— 一个只服务一个人的健身记录客户端（设计定稿）
- **Audience**: 主要读者是项目所有者本人（定稿存档）；次要读者是想了解这个项目的朋友或未来的协作者
- **Scenario**: 设计阶段收尾的定稿材料；也是将来向朋友介绍项目时可直接使用的一份
- **Language**: 中文（技术术语与标识符保留英文原文，如 `WorkoutSet`、`tool calling`）
- **Purpose / decision / action**: 让读者在 15 分钟内理解三件事，并认可「按此设计进入实施」
  1. 这个项目的立论是「只有一个用户」，以及由此推出的取舍；
  2. 六个核心决定各自的理由（不是喜好，有依据）；
  3. 可行性不是推测而是实测：关键风险已被真跑出来的数字消解。
- **Duration and page count**: 约 15 分钟讲解 / **18 页**
- **Source material**:
  - 设计文档 `docs/superpowers/specs/2026-10-14-change-design.md`
  - 三份调研（`docs/research/`）
  - 十五屏原型稿（`.superpowers/brainstorm/change/content/`）
  - 环境与 3D 的实测数据（本机真跑，非估算）
- **Brand, image, data, and editability constraints**:
  - **无品牌模板**，走 Build Mode 空白画布
  - **不使用需要凭据的 AI 生成图片**；需要视觉时用原生形状、图表与示意图
  - **所有数字必须来自实测或调研**，禁止编造精确指标
  - 技术内容保持**原生可编辑**（文字、形状、图表），不用整页截图承载关键信息
  - 字体必须用本机已确认存在的：**微软雅黑**（`msyh.ttc` / `msyhbd.ttc`）

## Outcome

读者合上这份材料后应能复述：

- **立论**：所有取舍都服从「只有一个用户」这一条。
- **六个决定**：桌面客户端 / 训练日志 / 饮食 per-100g / 智能体可读可写 / 3D 人体图排第二阶段 / 动作库三家各取所长。
- **证据**：Tauri 全链路编译 1.9 分钟产出 12 MB exe；3D 拾取从 14.96 ms 优化到 0.06 ms；环境侧已无未验证项。
- **风险与次序**：唯一的高风险项是 JDK 25 与 Spring Boot 3.x 的版本搭配，动工第一步就验证它。
